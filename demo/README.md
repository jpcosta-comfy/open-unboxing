# Demo output

Product stills in `product/` were generated with FLUX 3 on Comfy Cloud (unbranded sage ceramic pour-over, five angles).

The unboxing cut `unboxing.mp4` is a real Comfy Cloud run of the Open Unboxing pipeline against the kraft mailer preset:

1. ISNet cutout of the hero still  
2. Scale-fit into the magenta insert well  
3. FLUX 3 blend edit → nested keyframe  
4. LTX 2.5 Fast first-last-frame (sealed plate → nested plate), 720×1280, 3s, stereo ASMR audio  

Keyframes: `kf0_sealed.png`, `kf1_nested.png`. Still from the clip: `unboxing_frame.jpg`.
